# Security policy

Please report suspected vulnerabilities through GitHub's private vulnerability reporting for this repository. Do not place credentials, production identifiers, customer data, or confidential vulnerability details in a public issue.

The active release candidate on npm's `next` tag and, once available, the current `latest` line
receive best-effort security fixes. Older `0.x` lines do not receive guaranteed backports. This
project provides no response-time, remediation, or long-term-support SLA.

Before using a release in production, review the generated browser bundle and test the integration against the target Webflow project, its Content Security Policy, accessibility requirements, and supported browsers.
